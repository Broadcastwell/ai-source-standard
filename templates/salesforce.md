In Setup, Object Manager, Lead, Fields & Relationships, choose New and the stated type. Set field-level access only for the staff who need it. Preserve the option order and exact spelling. Reuse existing compatible fields rather than making duplicates. For conversion, the admin can map to already-approved corresponding Contact fields in Map Lead Fields; any additional object fields require its separate authorization.

In Setup, Web-to-Lead, Create Web-to-Lead Form, select the existing identity fields plus these two custom fields. Generate the HTML. Its generated custom field IDs are the required input name/id values, not the API names above. Map the visible ai_source selection to the generated AI_Source__c input ID and the optional question to the generated AI_Question_Asked__c ID. Retain the generated organization ID and return URL from that actual organization. Do not copy IDs from an example. A hidden technical referrer field never replaces AI_Source__c. Do not create an additional field just to store a referrer if analytics already has it.

An existing form integration may write the two API fields directly. If the admin's approved intake has staging fields, a before-save Record-Triggered Flow on Lead creation can use those existing inputs: Configure Start, Lead, A record is created, conditions restricted to the intended intake, Optimize for Fast Field Updates. A Decision validates membership in the exact ten options; an Assignment maps the submitted values to $Record.AI_Source__c and $Record.AI_Question_Asked__c. Preserve blank answers and do not infer a source. If Web-to-Lead already writes the target fields, no copy Flow is needed. No email, task or owner action belongs in this recipe.

Debug in the existing sandbox using a controlled test identity, confirm optional blanks and exact values, and have the admin activate its reviewed change. Test conversion and the opportunity association rule used in the report. Remove only the controlled test record under the client's policy. Export deduplicated aggregates, never raw Lead or Contact rows.
